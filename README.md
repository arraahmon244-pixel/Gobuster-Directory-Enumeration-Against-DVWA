## Gobuster Directory Enumeration Lab

A hands-on web reconnaissance lab demonstrating directory enumeration against DVWA using Gobuster on Kali Linux.

## Objectives

- Perform web directory enumeration
- Discover hidden resources
- Explore Gobuster flags
- Document findings

## Lab Environment

| Component | Value |
|-----------|-------|
| OS | Kali Linux |
| Target | DVWA |
| Tool | Gobuster v3.8.2 |
| Wordlist | dirb/common.txt |
