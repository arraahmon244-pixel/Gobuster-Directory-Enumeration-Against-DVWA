# Gobuster-Directory-Enumeration-Against-DVWA
A hands-on Gobuster directory enumeration lab using DVWA on Kali Linux, demonstrating web reconnaissance, hidden resource discovery, and practical penetration testing techniques.
Gobuster Directory Enumeration Lab demonstrates practical web reconnaissance using Gobuster against the Damn Vulnerable Web Application (DVWA) in a controlled Kali Linux environment
This project covers setting up DVWA, performing directory enumeration, exploring essential Gobuster flags, analyzing discovered resources, and documenting findings using industry-standard penetration testing practices
it is intended for educational purposes and highlights the importance of reconnaissance in identifying a web application's attack surface.
